# HTML 강의 슬라이드 제작

AI는 원고를 디자인하고 기계적으로 검증한다. 사람은 HTML 편집기에서 최종 구성을 다듬는다. 페이지 전체를 평면 이미지로 만들어 편집 가능성을 없애지 않는다. 사용자가 요청한 이미지 전면 페이지는 예외다.

## 입력과 디자인 합의

사용자가 전달한 원고·사진·강의 대상·디자인 요청을 먼저 읽는다. 노션 URL만 주어지면 연결된 노션 도구로 해당 페이지와 하위 콘텐츠를 읽는다. 연결할 수 없으면 그 사실을 말하고 제공된 원고로 진행한다. 실제로 읽지 않은 노션 내용을 추측하지 않는다.

이미 합의한 내용은 다시 묻지 않는다. 디자인이 정해지지 않았고 대화가 가능하면 [디자인 규칙](references/design.md)의 세 방향 중 선택하거나 참고 디자인을 받는다. 질문 없이 진행하라는 요청에는 원고에 맞춰 한 방향을 선택하고 선택 이유를 기록한다.

다음의 짧은 디자인 계약을 먼저 작성한다. 사용자가 정한 값은 그대로 반영한다.

```text
강의 대상과 목표:
분량과 페이지별 핵심 메시지:
템플릿 / 참고자료:
배경·본문·강조 색상:
제목·본문·보조 글자의 크기:
기본 여백과 이미지 처리:
표 스타일:
영상·애니메이션이 필요한 페이지:
```

## 제작

1. 원고를 페이지별 핵심 메시지로 나눈다. 원문에 없는 사실·수치·인용은 생성하지 않는다. 필요하면 근거를 확인하고 출처를 표시한다.
2. [디자인 규칙](references/design.md)을 적용한다. 같은 디자인 계약 안에서 텍스트, 이미지 한 장, 비교, 표, 영상 등 내용에 맞는 구성을 선택한다.
3. [HTML 규약](references/html-contract.md)을 따라 1280×720의 독립적인 페이지를 만든다. 제목·본문·표는 HTML로, 사진은 이미지로, 복잡한 동적 콘텐츠는 하나의 묶음으로 유지한다.
4. 이미지 생성이 필요한 경우 사용 가능한 이미지 생성 도구를 사용한다. 원고에 있는 사진을 임의로 대체하지 않는다. 이미지 생성이 불가능하면 빈 성공 표시 대신 필요한 에셋을 명확히 남긴다.
5. 리모션이 필요한 페이지는 사용 가능한 리모션 제작 환경에서 렌더링한 MP4/WebM을 넣는다. 리모션 소스만 전달하고 영상이 재생된다고 주장하지 않는다. 영상 내부 수정은 AI 제작 단계에서 수행하며, 편집기는 완성된 영상의 위치·크기·교체를 담당한다.
6. 글자가 많으면 내용을 재구성하거나 페이지를 나눈다. 무조건 글자 크기를 줄이지 않는다.

## 렌더링 검증과 수정

실제 Chromium 브라우저로 모든 페이지를 렌더링하고 글꼴·이미지가 로딩된 후 검사한다. 검증 절차는 [검증 규칙](references/validation.md)을 따른다.

프로젝트에 포함된 검사 도구를 사용할 수 있으면:

```powershell
node scripts/validate-slides.mjs "강의.html" "검증결과폴더"
```

검사기는 페이지별 스크린샷과 JSON 보고서를 만든다. 경계 초과, 텍스트 넘침, 누락 이미지, 작은 글자, 겹침을 확인한다. 자동 검사 통과는 디자인 검토의 대체가 아니다. 스크린샷을 직접 열어 한국어 줄바꿈, 의도된 겹침, 시각적 균형, 이미지 비율과 잘림을 확인한다. 발견한 문제를 수정하고 영향을 받은 페이지를 다시 검사한다.

동적 페이지는 편집 화면과 별도로 격리된 미리보기에서 재생을 확인한다. 콘솔 오류, 미디어 로딩, 재생 시간의 실제 증가, 필요한 외부 의존성을 확인한다. 정지 화면만 보고 애니메이션이 정상이라고 보고하지 않는다.

프로젝트 검사기를 찾을 수 없으면 현재 프로젝트에서 `scripts/validate-slides.mjs`를 검색한다. 없으면 Playwright 등 사용 가능한 브라우저 도구로 동등한 검증을 수행한다. 실행하지 않은 검증을 통과했다고 보고하지 않는다.

## 인계

- 원고에서 페이지로의 대응, 디자인 계약, 편집 가능한 HTML, 필요한 에셋을 전달한다.
- HTML을 편집기에 불러와 제목 수정, 이미지 이동, 표 셀 수정 중 해당 작업을 실행하고 다운로드 후 다시 연다.
- 스크린샷 및 검사 보고서, 수정한 문제, 남은 제한을 전달한다.
- 외부 CDN·폰트·영상 의존성을 명시한다. 외부 연결이 남아 있으면 완전한 오프라인 파일이라고 부르지 않는다.
- 사용자가 승인하지 않은 게시·공유·노션 수정은 수행하지 않는다.
