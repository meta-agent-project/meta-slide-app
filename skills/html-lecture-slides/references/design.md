# 디자인 선택과 생성 프롬프트 규칙

## 템플릿 방향

| 방향 | 배경 / 본문 / 강조 | 사용 맥락 |
| --- | --- | --- |
| 차분한 에디토리얼 | #F8F6F0 / #253F38 / #8DA994 | 인문·교육·설명 중심 |
| 선명한 세미나 | #FFFFFF / #1E293B / #5865E8 | 실무·기술·데이터 비교 |
| 어두운 시네마 | #151D28 / #F1F5F9 / #EAB285 | 이미지·영상·도입 장면 |

템플릿은 시작점이다. 사용자 참고 디자인이 있으면 색상과 밀도 등을 그에 맞게 바꾼다. 모든 슬라이드를 동일한 카드 배치로 반복하지 않는다.

## 공통 수치

- 1280×720. 외곽 안전 여백 기본 64px, 하단 출처 영역 40px 이상.
- 제목 48~68px, 본문 26~32px, 표 22~28px, 출처 16~18px. 예외는 실제 렌더링 후 가독성을 판단한다.
- 한국어 본문 line-height 1.45~1.65, 제목 1.15~1.3. 제목과 본문 사이에 충분한 여백을 둔다.
- 텍스트에 고정 높이를 사용할 때 실제 줄 수를 검증한다. 복잡한 설명은 다음 페이지로 나눈다.
- 사진에는 의미 있는 alt를 제공한다. 인물·도표의 중요한 부분을 cover로 잘라내지 않는다.
- 표는 행·열 제목을 명확히 하고, 병합은 의미 있는 상위 분류에만 사용한다. 읽기 어려운 표는 여러 장으로 나눈다.
- 장식은 `data-decorative`, 의도된 겹침은 해당 요소에 `data-allow-overlap`, 작은 출처는 `data-caption`을 붙인다. 오류를 숨기기 위해 표시하지 않는다.

## 생성 프롬프트 골격

```text
다음 원고를 [대상]을 위한 [분량]의 강의 슬라이드로 구성한다.
핵심 메시지와 원고의 의미를 보존한다. 없는 사실과 수치는 추가하지 않는다.
디자인 계약: [템플릿, 색상, 글꼴, 크기 단계, 여백, 이미지 처리, 표 규칙].
각 페이지는 하나의 핵심 메시지를 담되, 내용에 따라 제목·본문 / 이미지 전면 /
비교 / 표 / 영상의 구성을 선택한다. 모든 페이지를 리모션으로 만들지 않는다.
텍스트·이미지·도형·표를 HTML 요소로 분리해 인간이 다시 편집할 수 있게 한다.
리모션 결과는 완성된 영상으로 넣거나 자체 완결된 동적 묶음으로 제공한다.
1280×720 실제 렌더링으로 넘침·잘림·겹침·이미지·글꼴을 검사하고 수정한다.
```

## 이미지 생성에 전달할 정보

이미지의 교육적 역할, 주제, 피사체, 구도, 페이지에서 차지할 비율, 여백 위치, 색감과 금지할 왜곡을 전달한다. 이미지 안에 긴 한국어 문장을 그리게 하지 말고 HTML 텍스트로 배치한다. 사실적 자료를 생성 이미지로 대체하면 생성 이미지임을 구분한다.
