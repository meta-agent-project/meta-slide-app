# 슬라이드룸 · HTML 강의 슬라이드 제작과 편집

노션의 글과 사진을 AI와 함께 HTML 강의 슬라이드로 만들고, 사람이 PPT처럼 최종 구성을 다듬는 로컬 도구입니다.

## 실행

**`start.cmd`를 더블클릭하세요.** 브라우저에서 `http://127.0.0.1:4173`이 열립니다.

- Node.js 22 이상이 필요합니다. 현재 작업 컴퓨터에는 설치되어 있습니다.
- 편집기 실행에는 npm 패키지 설치나 인터넷 연결이 필요하지 않습니다. 외부 URL을 사용하는 강의 자료는 별도입니다.
- 터미널에서 실행하려면 `npm start`를 사용합니다.
- `index.html`을 직접 더블클릭하는 대신 시작 파일을 사용하세요. 편집기는 브라우저 모듈과 로컬 저장소를 사용합니다.
- 시작 파일로 실행한 서버를 종료하려면 `powershell -ExecutionPolicy Bypass -File scripts/stop.ps1`을 실행합니다.

## 사용 순서

1. **파일 → 열기**에서 AI가 만든 HTML 또는 저장한 `.slide.json`을 선택합니다.
2. 이미지나 CSS가 별도 파일이면 오른쪽 **속성 → 문서 설정 → 리소스 → 폴더 선택**으로 원래 폴더를 연결합니다.
3. 요소를 클릭해 선택하고 드래그로 이동합니다. 모서리 손잡이 또는 오른쪽 X/Y/W/H로 크기와 위치를 바꿉니다.
4. 글자와 표 셀은 **더블클릭**해서 수정합니다. 텍스트·도형·이미지·영상·표는 상단 도구에서 추가합니다.
5. **검사**로 현재 페이지의 넘침·잘림·이미지 누락을 확인하고, **미리보기**로 재생과 전체 구성을 확인합니다.
6. **파일 → 프로젝트 저장**은 다시 편집할 프로젝트 JSON, **HTML 내보내기**는 브라우저에서 바로 여는 강의 파일을 내려받습니다. 내보낸 HTML도 다시 불러와 편집할 수 있습니다.

브라우저에는 작업을 자동 저장합니다. 중요한 작업은 파일로도 저장하세요. 새 작업으로 전환한 직후에는 실행 취소로 이전 작업을 복구할 수 있습니다. 다른 파일을 열 때는 새 실행 취소 이력을 시작합니다.

## 테마 페이지와 PPT식 편집

왼쪽 **테마 · 내 페이지**에서 슬라이드룸 도트 테마의 20종 페이지를 가져옵니다. 표지, 핵심 개념, 좌우 비교, 단계별 흐름, 표·목록·이미지 조합 등을 하나씩 또는 모두 추가할 수 있습니다. 페이지는 이미지가 아닌 개별 텍스트·도형으로 만들어져 직접 수정할 수 있습니다.

- 테마 이름·배경·글자·주조색·강조색·글꼴을 바꾸고 **이 문서의 테마 페이지에 적용**하면 같은 테마 변수를 사용하는 페이지가 함께 바뀝니다. 직접 지정한 개별 서식은 유지합니다. 외부 HTML 전체에 스타일을 강제로 덮어쓰지 않습니다.
- **현재 페이지 보관**으로 완성한 일반 페이지를 ‘내 페이지’에 보관합니다. 다른 문서에서도 독립된 복사본을 가져올 수 있습니다. 보관함은 이 브라우저의 IndexedDB에 저장되므로 중요한 내용은 프로젝트 파일로도 백업하세요.
- Shift+클릭 또는 빈 공간 드래그로 여러 요소를 선택합니다. 함께 이동·복제·삭제하거나 **속성 → 배치**에서 정렬·동일 간격을 적용할 수 있습니다. 정렬 기준은 선택 영역 또는 슬라이드입니다.
- 이동할 때 가장자리와 중앙에 스마트 가이드가 표시됩니다. **Alt**를 누르면 잠시 스냅을 끕니다.
- **그룹 만들기/해제**는 원본 HTML의 부모 구조를 바꾸지 않고 함께 선택·이동하도록 묶습니다. **Ctrl+G / Ctrl+Shift+G**를 지원합니다.
- **서식 복사 → 대상 선택 → 서식 적용**으로 텍스트나 도형의 모양을 복사합니다. 위치·크기는 유지합니다. 단축키는 **Ctrl+Shift+C / Ctrl+Shift+V**입니다.
- 오른쪽 **레이어**에서 요소 잠금·해제, 숨김·보이기, 앞뒤 순서를 바꿀 수 있습니다. 이름은 더블클릭해 수정합니다. 잠근 요소는 캔버스에서 이동·삭제하지 않습니다.
- 크기 조절 손잡이는 8방향입니다. 이미지는 기본적으로 비율을 유지하며 속성에서 해제할 수 있습니다. 확대율은 하단에서 직접 입력합니다. 양쪽 패널은 접거나 경계를 끌어 폭을 조절합니다.
- **전체 보기**에서는 슬라이드 이름·섹션을 편집하고 드래그 또는 이동 버튼으로 순서를 바꿉니다.
- **발표 노트**를 작성한 뒤 **발표 시작 → 청중 화면 열기**를 누릅니다. 발표자는 현재/다음 페이지·노트·경과 시간을 보고, 청중 창에는 슬라이드만 표시합니다. 청중 창을 다른 모니터로 옮기고 전체 화면으로 전환할 수 있습니다.
- **검사**에서 문제 위치로 이동하거나 넘침·텍스트 상자 크기·작은 글씨의 수정 결과를 미리 본 뒤 적용합니다. 적용 후에는 실행 취소가 가능합니다. 자동 검사는 시각 검토를 대체하지 않습니다.

JavaScript 원본 실행을 유지하는 페이지에는 기존 편집 범위가 적용됩니다. 원본 글자 내용과 도형 위치·크기는 수정할 수 있지만 서식·그룹·레이어 변경은 제한합니다. 이런 문서에도 일반 페이지와 테마 페이지를 추가해 편집할 수 있습니다. 발표 화면의 원본 페이지는 원래 스크립트를 실행하며, 다음 페이지 미리보기는 편집용 스냅샷입니다.

## 자유로운 HTML 불러오기

자체 규약이 없는 HTML도 DOM과 CSS를 유지하면서 가져옵니다. `[data-slide]`, `.slide`, 일반적인 section 페이지를 감지합니다. 구분이 잘못되면 불러온 뒤 **페이지 구분**에서 CSS 선택자를 지정할 수 있습니다.

1920×1080 등 다른 해상도의 16:9 페이지는 편집 화면에 맞춰 조정합니다. 겹친 요소는 오른쪽 **오브젝트** 목록에서 선택합니다. 내부를 편집하기 어려운 SVG·Canvas·iframe은 묶음으로 다룹니다.

JavaScript로 화면 전체를 만드는 자료 등 일반 요소 편집이 어려운 HTML은 **페이지 통째로 묶기**를 사용하세요. 원래 HTML을 격리된 프레임에서 실행하는 하나의 오브젝트가 됩니다. 실행 취소로 원래 구조로 돌아갈 수 있습니다.

## 리모션과 외부 의존성

리모션은 **렌더링을 마친 MP4/WebM 영상**을 올리는 방식으로 지원합니다. 영상 내부의 문구·애니메이션을 바꾸는 타임라인 편집기는 아닙니다. 해당 변경은 AI와 리모션 제작 단계에서 합니다.

Canvas나 스크립트가 있는 HTML은 격리된 화면에서 원본을 재생합니다. 인증, 서버 API, 외부 모듈·CDN 등 실행 환경에 의존하는 HTML은 해당 환경이 제공되어야 합니다. 원본 React/Remotion 소스 프로젝트를 HTML 파일처럼 직접 실행하지는 않습니다.

업로드한 이미지·영상과 연결한 로컬 에셋은 HTML에 포함됩니다. 아직 외부 URL을 참조하는 자료는 **리소스** 목록에 표시됩니다. 큰 영상을 많이 넣으면 HTML 크기와 브라우저 메모리 사용량이 증가합니다. 파일 연결은 일반적인 CSS `url()`과 `@import`, 이미지·폰트·영상·스크립트 경로를 지원하며, JavaScript 내부의 동적 import 경로를 자동 재작성하지 않습니다.

## 에셋과 제목 분류

상단 **에셋**에서 GPT로 생성한 투명 PNG 50개를 검색하고 삽입할 수 있습니다. 사람·동물·디지털·학습/업무·사물/개념으로 분류하며, 한글 이름과 동의어(예: 휴대폰·핸드폰·스마트폰) 검색을 지원합니다. 삽입한 그림은 프로젝트 및 HTML에 데이터로 포함되어 사이트 연결 없이도 표시됩니다. 원본 실행형 페이지는 기존 제한을 유지하므로 새 일반/테마 페이지에 삽입하세요.

도트 테마는 연한 회백색 배경과 점무늬를 사용합니다. 상단의 `00. 도입`은 **대제목(장 제목)**, 큰 핵심 문장은 **중제목(절 제목)**입니다. 텍스트를 선택하면 속성의 **텍스트 분류**에서 역할을 바꿀 수 있고 레이어와 선택 표시에도 구분이 나타납니다. 글자 크기와 역할은 독립적입니다.

## 이미지 배치와 도형 입력

이미지와 에셋은 기본 Cover로 삽입합니다. 이미지 선택 시 속성 상단에서 Cover(영역 채우기), Contain(전체 보이기), Fill(늘려 채우기)을 고를 수 있습니다. 좌우 핸들은 가로만, 위아래 핸들은 세로만 변경하며 모서리는 기본적으로 비율을 유지합니다. 비율 유지 옵션을 끄면 모서리에서도 자유롭게 조절합니다.

삽입 메뉴의 도형 버튼은 네모·원·둥근 네모·선·화살표로 펼쳐져 있습니다. 도형 기본값은 흰 배경과 검정 1px 테두리이며 선은 검정 1px입니다. 네모·원·둥근 네모를 더블클릭하면 가로·세로 가운데 정렬된 글자를 입력합니다. 도형과 글자는 함께 이동·저장됩니다.

## 오브젝트 회전

텍스트·도형·이미지·영상·SVG·임베드 오브젝트를 선택하면 회전 핸들과 각도 입력이 나타납니다. 핸들을 끌어 자유롭게 회전하고 Shift를 누르면 15° 간격으로 맞춥니다. 속성에서 정확한 각도, 좌우 90° 회전, 0° 초기화를 사용할 수 있습니다. 여러 오브젝트를 선택하면 공통 중심을 기준으로 함께 회전합니다. 회전은 실행 취소·다시 실행과 저장·HTML 내보내기에 반영됩니다.
