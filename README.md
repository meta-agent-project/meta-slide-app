# HTML 강의 슬라이드 제작·편집 도구

노션에서 작성한 글과 사진을 AI와 함께 HTML 강의 슬라이드로 만들고, 사람이 시각적 편집기로 최종 구성을 완성하는 로컬 프로젝트입니다.

## 현재 상태

요구사항 합의 및 개발 시작 기준점입니다. **실행 가능한 편집기는 아직 없습니다.**

- `index.html`, `style.css`: 요구사항 협의 전에 작성한 화면 초안. 실제 편집 로직인 `app.js`는 아직 없으며, 최종 설계에 맞춰 수정할 예정입니다.
- [PLAN.md](PLAN.md): 합의된 범위, 설계 방향, 구현 순서와 검증 기준.

## 결과물

1. 디자인 템플릿 선택 규칙과 렌더링 검증 절차를 포함한 HTML 강의 슬라이드 제작 스킬.
2. AI가 만든 HTML을 불러와 PPT처럼 편집하고 HTML로 내려받는 로컬 브라우저 편집기.

## 사용 흐름

노션 원고·사진 → AI와 대화하며 슬라이드 제작 → AI 렌더링 검증 및 수정 → HTML 불러오기 → 사람이 최종 편집 → 저장 및 HTML 다운로드.

노션 직접 연동은 첫 버전의 필수 기능이 아닙니다. 사용자가 전달한 원고·사진으로 시작하며, 연결 도구가 있을 때만 노션을 읽습니다.
