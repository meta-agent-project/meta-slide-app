# 발표용 에셋 생성 기록

내장 GPT imagegen 도구를 사용해 이미지별로 생성했습니다. transparent_background=true로 요청했으며 원본 알파 채널을 유지합니다. 생성 결과를 assets/clipart에 복사했습니다.

## 공통 프롬프트

Use case: productivity-visual. Create ONE isolated presentation clipart asset: {subject}. Clean minimal black ink outline cartoon, white object interiors, simple friendly rounded forms, consistent thin strokes. Entire subject visible centered with 12% margin on all sides. Genuine transparent alpha background. No backdrop, no glow, no shadow, no texture, no colors, no labels, no watermark. Small-size legibility. Only the requested subject.
